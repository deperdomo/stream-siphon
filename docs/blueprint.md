# **App Name**: StreamSiphon

## Core Features:

- URL Analysis: Analyzes the provided YouTube URL to extract video metadata such as title, duration, available formats, and thumbnail using a tool. Returns error if it's invalid.
- Format Selection: Allows users to select the desired download format (MP4, MP3, M4A) and quality (4K, 1080p, 720p, 480p) from the available options.
- Download Initiation: Initiates the video or audio download based on user-selected preferences.
- Download Progress Display: Shows real-time download progress using a smooth, animated progress bar and percentage indicator.
- Video Preview: Displays video metadata (thumbnail, title, duration) before download to verify the content.
- Error Handling: Provides informative error messages when an invalid URL is provided or the download fails.

## Style Guidelines:

- Primary color: A vibrant shade of purple (#6246EA) is chosen for its modern and unique feel.
- Background color: A very light gray (#F4F4F4) will give the design a clean and minimalist feel.
- Accent color: Use a turquoise shade (#3AB0FF) to add contrast.
- Font: 'Inter', a grotesque-style sans-serif font, is recommended for both headlines and body text.
- Modern, minimalist layout with generous whitespace and rounded borders (border-radius: 12px) for a clean and user-friendly interface.
- Smooth transitions (300ms) and micro-animations for interactive elements such as the download button and progress bar. Add loading states and progress states to relevant components.
- Use simple and modern icons from Lucide, Heroicons, or Feather for key actions and elements (e.g., download, analyze, settings).
